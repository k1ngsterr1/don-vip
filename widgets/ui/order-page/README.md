# Order Page Components

Эта папка содержит все компоненты для страницы заказа Don-VIP, реализующие дизайн из Figma.

## Основные компоненты

### OrderBlock

Основной компонент страницы заказа, который объединяет все остальные компоненты.

### DiamondPackages

Компонент для отображения пакетов алмазов/валюты с ценами, скидками и популярными предложениями.

**Особенности:**

- Поддержка скидок и бейджей "ОК"
- Отметка популярных пакетов
- Адаптивный дизайн
- Поддержка разных валют

### ReviewsSection

Секция с отзывами пользователей.

**Особенности:**

- Отображение аватаров пользователей
- Рейтинги и даты
- Кнопки лайков/дизлайков
- Информация об играх

### FAQSection

Интерактивная секция с часто задаваемыми вопросами.

**Особенности:**

- Раскрывающиеся ответы
- Эмодзи иконки для вопросов
- Стилизованные границы

### InstructionSection

Табы для переключения между инструкцией, описанием, отзывами и FAQ.

**Компоненты:**

- `InstructionTabs` - навигация по табам
- `InstructionContent` - содержимое инструкции с шагами

### GameDescription

Подробное описание игры с иконкой, названием и характеристиками.

### PromoBlock

Блок с предложением скидки за подписку в Telegram.

### InfoBlock

Блок с преимуществами сервиса (скорость, регионы, цены и т.д.).

### OrderFooter

Футер с ссылками на документы и копирайтом.

### BottomNavigation

Нижняя навигация для мобильной версии.

## Стили

Все компоненты используют Tailwind CSS для стилизации. Основная цветовая схема:

- `#eeeff3` - светло-серый фон
- `#f3f4f7` - фон кнопок и карточек
- `#1c34ff` - синий цвет для ссылок
- `#ff272c` - красный цвет для цен
- `#03cc60` - зеленый цвет для успеха

## Использование

```tsx
import { OrderBlock } from "@/widgets/ui/order-page";

function OrderPage({ gameSlug }: { gameSlug: number }) {
  return <OrderBlock gameSlug={gameSlug} />;
}
```

## Мобильная версия

Все компоненты оптимизированы для мобильных устройств и следуют дизайну из Figma:

- Фиксированная кнопка покупки в правом нижнем углу
- Нижняя навигация
- Табы для переключения контента
- Адаптивные размеры и отступы
